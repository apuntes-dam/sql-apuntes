# U1 · Primeros pasos con SQL

**SQL** es el lenguaje con el que se habla con las bases de datos relacionales: sirve para **guardar, consultar, modificar y borrar** información. En esta unidad aprendes qué es una base de datos, conoces la base de datos de ejemplo que se usa en toda la web y escribes tus primeras consultas con `SELECT`.

## Teoría

1. [Bases de datos y SQL](01-bases-de-datos.md)
2. [SELECT: pedir datos](02-select.md)
3. [WHERE: filtrar filas](03-where.md)
4. [Ordenar, limitar y funciones](04-ordenar-funciones.md)

## Antes de empezar: qué debes dominar

* Saber qué es una tabla, una fila y una columna (se repasa en el primer apartado).
* Tener a mano una herramienta donde escribir y ejecutar SQL (ver el apartado 1.1).
