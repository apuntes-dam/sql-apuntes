# A2 · CTE recursivas y jerarquías

Los organigramas, las categorías con subcategorías y las rutas de un mapa tienen algo en común: **no se sabe cuántos niveles hay**. Una consulta normal no puede recorrerlos, pero una **CTE recursiva** sí. Aquí aprendes a recorrer **árboles** y **grafos**, a evitar los **ciclos** y a **generar series** como calendarios.
